# PortableAI v0.3.5 · 安全退出与设备弹出

本版完善便携使用后的退出体验，减少后台服务残留导致 U 盘无法弹出的情况。

网页点击“退出并安全弹出”，CLI 输入 `/eject`，也可双击 `Safe-Exit-Windows.cmd`。程序保存记录、停止此目录的 PortableAI 实例，再请求 Windows 安全弹出。只有系统确认成功才提示可以拔出；其他应用占用时明确提示，不强制结束其他程序。

重复启动网页入口复用已有服务。关闭 CLI 窗口会清理其子进程；关闭最后一个网页会退出后台，页面刷新与其他页面可继续使用。关闭程序后仍应通过安全弹出入口确认设备状态。

系统弹出入口目前支持 Windows。源码包不包含模型、运行环境、个人配置、API 密钥和会话。
