# PortableAI v0.3.4 · 便携 AI 编程工作区

将持续交互的编程工作区与云端 API、本地模型结合，保留独立的浏览器聊天入口。

## 改进设计

- **云端优先、本地接续**：填写自有 API 地址、模型和密钥，支持请求失败后自动降级，也可以直接指定本地模型。
- **持续编程体验**：完成一轮后继续输入，保留当前会话上下文；读取文件、修改代码、运行测试并根据结果继续处理。
- **按存储条件读取模型**：检查文件系统和权重布局，优先直接读取完整模型；必要时使用已有电脑权重或缓存，减少重复准备。
- **会话随设备携带**：从 U 盘版本启动时，会话、配置和修改记录保存在 U 盘，可继续已有任务。
- **更清晰的终端配色**：正文跟随终端主题，灰色区分边框和辅助信息，仅用少量状态色。
- **两种使用入口**：CLI 面向编程任务，网页入口面向聊天，共用连接设置。

## 发布内容

此次发布为源码预览版，包含程序、启动入口、使用指南、测试和许可证。**不包含模型权重、API 密钥、个人配置、会话记录、日志或完整便携运行环境。**

源码使用需要 Node.js 22+，在项目目录执行 npm ci 后运行 node cli.mjs --connect。完整便携运行包需要自行准备对应平台的 Node/Ollama 程序及可选模型，参见 [便携部署指南](../PORTABLE.md)。

## 当前支持范围

Windows x64 已验证。其他操作系统、ARM64 和手机暂无经过验证的完整运行包。支持会话保存与恢复，尚无跨会话长期记忆或自动摘要；恢复会话目前要求原项目路径一致。本地任务能力取决于模型和硬件。

本版通过 49 项自动化测试，并验证真实本地代码修复、模拟云端故障后的本地接续和跨进程会话恢复。小型测试结果不代表完整编程能力榜单成绩。
